# wombat-wiki

This is a personal knowledge base — a markdown vault where notes live as `<category>/<slug>.md` files, organized into short lowercase category folders (`dev`, `ideas`, `books`, etc.).

To save a note, use: **`/add <your thought>`**

That command handles categorization, summaries, deduplication, and writing the file.

Do not process free-form conversation as notes. Only act on an explicit `/add`.
